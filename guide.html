คู่มือขั้นตอนการพัฒนาโปรเจกต์ (Step-by-Step Guide)

พัฒนาโดย: งานวิทยบริการและเทคโนโลยีการศึกษา

สารบัญขั้นตอนการพัฒนา (8 ขั้นตอนหลัก)

1

การวิเคราะห์ความต้องการและการออกแบบโครงสร้างข้อมูล (Requirements Analysis)

ขั้นตอนแรกคือการรวบรวมข้อกำหนดทางธุรกิจ (Business Rules) ของวิทยาลัยเทคนิคอุดรธานี สำหรับโครงการหนังสือเรียนฟรี ระดับ ปวช. โดยสรุปโครงสร้างข้อมูลสำคัญดังนี้:

  • ขอบเขตระดับชั้น: ระดับ ปวช.1, ปวช.2 และ ปวช.3
  • โครงสร้างภาคเรียน: แยกปีการศึกษา (พ.ศ.) และภาคเรียน (ภาคเรียนที่ 1 และ ภาคเรียนที่ 2)
  • โครงสร้างรายการสั่งซื้อ: แต่ละรายการประกอบด้วย ปีการศึกษา, ภาคเรียน, แผนกวิชา, ระดับชั้น, รหัสวิชา, ชื่อหนังสือ, ผู้แต่ง, สำนักพิมพ์, จำนวนเล่ม, และ ราคาต่อเล่ม
  • ระบบคำนวณงบประมาณ: ราคารวม (Amount) = จำนวนเล่ม (Qty) × ราคาต่อเล่ม (Price)

การวางโครงสร้าง UI และระบบดีไซน์ (Design System & CSS)

เราเลือกใช้ **Vanilla CSS** เพื่อให้ระบบโหลดเร็วและควบคุมสไตล์ได้อย่างสมบูรณ์ โดยสร้าง Design System ด้วย **CSS Custom Properties (Variables)** รองรับทั้ง Light Theme และ Dark Mode:

/* Example Design System Variables in styles.css */
:root {
    --primary-color: #1e3a8a;
    --primary-light: #eff6ff;
    --secondary-color: #0284c7;
    --accent-color: #10b981;
    --bg-main: #f8fafc;
    --card-bg: #ffffff;
    --text-main: #0f172a;
    --radius-md: 12px;
    --shadow-sm: 0 4px 6px -1px rgba(0,0,0,0.05);
}

body.theme-dark {
    --bg-main: #0f172a;
    --card-bg: #1e293b;
    --text-main: #f8fafc;
}
จุดเด่นของสถาปัตยกรรม UI
ใช้ฟอนต์ **Prompt** จาก Google Fonts ร่วมกับ **Font Awesome 6 Icons** และดีไซน์แบบ Glassmorphism ช่วยให้ระบบดูทันสมัย Premium พรีเมียม และสบายตา

การจัดการข้อมูลในความจำและการบันทึก (State Management & Security)

การบริหารจัดการข้อมูลภายในแอปพลิเคชัน (SPA Architecture) ถูกรวมไว้ที่ state object เดียวใน app.js และใช้ **SHA-256 Hash Algorithm** สำหรับความปลอดภัยในโหมดผู้ดูแลระบบ (Admin):

// Central Application State
let state = {
    orders: [],
    isAdmin: false,
    selectedYear: '2569',
    selectedSemester: 'ภาคเรียนที่ 1',
    customYears: [2569],
    adminPassHash: "ae5c8040951ce84e4e933d89b556cfd6d0b316acc290a40d389542dba7aabdbc", // SHA-256
    targetSubjects: { ... },
    showSubjectCheckDashboard: true
};

// SHA-256 Encryption Function
async function sha256(message) {
    const msgBuffer = new TextEncoder().encode(message);
    const hashBuffer = await crypto.subtle.digest('SHA-256', msgBuffer);
    const hashArray = Array.from(new Uint8Array(hashBuffer));
    return hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
}
4

การเชื่อมต่อฐานข้อมูลคลาวด์สด (Firebase Realtime Database Integration)

เพื่อรองรับการทำงานร่วมกันแบบ Realtime ของทีมงาน ได้ทำการเชื่อมต่อกับ **Firebase Web SDK (v9 compat)** ผ่าน CDN และสร้าง Event Listener ดักฟังการเปลี่ยนแปลงข้อมูลเรียลไทม์:

// Initialize Firebase and Realtime Data Sync
function initFirebaseConnection() {
    let configObj = parseFirebaseConfigInput(savedConfigStr) || DEFAULT_FIREBASE_CONFIG;
    
    if (!firebase.apps.length) {
        firebase.initializeApp(configObj);
    }
    firebaseDb = firebase.database();
    isFirebaseConnected = true;

    // Realtime Orders Sync Across All Connected Clients
    firebaseDb.ref('orders').on('value', (snapshot) => {
        const data = snapshot.val();
        if (data && Array.isArray(data)) {
            state.orders = data;
            localStorage.setItem('freebook_orders', JSON.stringify(data));
            renderAllViews();
        }
    });
}

ระบบคลีนข้อมูลและการรวมรายการซ้ำอัตโนมัติ (Data Normalization & Auto-Merging)

แก้ไขปัญหาความผิดพลาดของการเว้นวรรคไม่เท่ากัน (เช่น ศูนย์หนังสือเมืองไทย vs ศูนย์ หนังสือเมืองไทย) ด้วยระบบ **Text Normalization** และทำการรวมยอดเล่มหนังสืออัตโนมัติเมื่อคีย์วิชาเดียวกันซ้ำ:

// Text Normalization (Removes redundant extra whitespace)
function normalizeText(str) {
    if (!str) return '';
    return String(str).replace(/\s+/g, ' ').trim();
}

// Auto-Merging duplicate entries
const existingIndex = state.orders.findIndex(o => 
    o.year === year &&
    o.semester === semester &&
    getNormalizedKey(o.dept) === getNormalizedKey(dept) &&
    getNormalizedKey(o.grade) === getNormalizedKey(grade) &&
    getNormalizedKey(o.code) === getNormalizedKey(code) &&
    getNormalizedKey(o.title) === getNormalizedKey(title)
);

if (existingIndex !== -1) {
    state.orders[existingIndex].qty += qty; // Merge Quantity!
    state.orders[existingIndex].amount = state.orders[existingIndex].qty * price;
}
6

การพัฒนาระบบ Dashboard และแผนภูมิสถิติ (Chart.js Visualization)

ใช้ไลบรารี **Chart.js** เพื่อสร้างแผนภูมิแบบโต้ตอบ 3 รูปแบบหลัก:

  1. Doughnut Chart: แสดงสัดส่วนงบประมาณแยกตามแผนกวิชา
  2. Bar Chart: แสดงงบประมาณแยกตามสำนักพิมพ์
  3. Stacked Group Bar Chart: แสดงการเปรียบเทียบงบประมาณตามระดับชั้น (ปวช.1, ปวช.2, ปวช.3)
7

การพัฒนาโมดูลนำเข้าไฟล์ Excel และแม่แบบ (SheetJS Integration)

รวมไลบรารี **SheetJS (`xlsx.full.min.js`)** ช่วยให้ผู้ดูแลระบบสามารถอัปโหลดไฟล์ Excel (.xlsx, .xls, .csv) เพื่อนำเข้าข้อมูลหลายร้อยรายการได้ใน 1 คลิก พร้อมทั้งปุ่มดาวน์โหลดไฟล์แม่แบบต้นแบบมาตรฐาน

8

การสร้างรายงานสรุปตามแบบมาตรฐาน สอศ. และการพิมพ์ PDF

ออกแบบตารางสรุปงบประมาณตามแบบฟอร์มทางการของ **สำนักงานคณะกรรมการการอาชีวศึกษา (สอศ.)** และรวมเอนจินการส่งออกไฟล์ PDF ผ่าน **`html2pdf.js`** เพื่อแปลงหน้าจอเป็นไฟล์ PDF คุณภาพสูง
