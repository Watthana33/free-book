คู่มือการนำซอร์สโค้ดขึ้น GitHub และตั้งค่า Auto Deploy ด้วย Netlify

สเต็ปที่ 1: เตรียมความพร้อม (ทำแค่ครั้งแรกครั้งเดียว)
1. ไปที่เว็บ github.com แล้วสมัครสมาชิกให้เรียบร้อย (จด Username และ Password ไว้ด้วย)
2. ดาวน์โหลดและติดตั้งโปรแกรม Git ที่นี่: git-scm.com/downloads (กด Next ไปเรื่อยๆ จนจบ)
3. เปิด Command Prompt หรือ Terminal ใน VS Code
4. พิมพ์ 2 คำสั่งนี้เพื่อยืนยันตัวตน (เปลี่ยนชื่อและอีเมลเป็นของคุณ):
   git config --global user.name "ชื่อของคุณ"
   git config --global user.email "อีเมลของคุณ@gmail.com"

สเต็ปที่ 2: สร้างกล่องเก็บโค้ดบนเว็บ GitHub
1. ล็อกอินเข้าเว็บ GitHub กดปุ่ม "+" มุมขวาบน เลือก "New repository"
2. ตั้งชื่อโปรเจกต์ เช่น free-book-system
3. เลือกเป็น Private (เพื่อความเป็นส่วนตัว)
4. ไม่ต้องเลือก Add a README
5. กดปุ่มสีเขียว "Create repository" (เปิดหน้านี้ทิ้งไว้เพื่อใช้ลิงก์ในสเต็ปที่ 3)

สเต็ปที่ 3: เอาโค้ดจากเครื่องเรา ดันขึ้นไปเก็บบน GitHub
1. เปิด Command Prompt หรือ Terminal แล้วชี้ไปที่โฟลเดอร์โปรเจกต์ (C:\Users\Acer\Desktop\free_book)
2. พิมพ์คำสั่งเหล่านี้ทีละบรรทัด แล้วกด Enter:
   git init
   git add .
   git commit -m "อัปโหลดโปรเจกต์ครั้งแรก"
   git branch -M main
   git remote add origin https://github.com/ชื่อผู้ใช้ของคุณ/free-book-system.git
   (อย่าลืมเปลี่ยนลิงก์ข้างบนเป็นลิงก์ของคุณที่ได้จากหน้าเว็บในสเต็ปที่ 2)
   git push -u origin main
   (ถ้ามีหน้าต่างเด้งขึ้นมา ให้ใส่ Username/Password ของ GitHub หรือกดยืนยันผ่านเบราว์เซอร์)

สเต็ปที่ 4: ผูก GitHub เข้ากับ Netlify ให้อัปเดตอัตโนมัติ
1. ไปที่เว็บ netlify.com แล้วล็อกอิน (กด Continue with GitHub)
2. กดปุ่ม "Add new site" -> "Import an existing project"
3. เลือก "GitHub" (กด Authorize เพื่ออนุญาต)
4. ค้นหาและคลิกเลือกชื่อ Repository ของเรา (free-book-system)
5. เลื่อนลงมาล่างสุด กดปุ่ม "Deploy site"
6. รอสักครู่ Netlify จะสร้างลิงก์เว็บไซต์ให้คุณนำไปใช้งานได้เลย

🚀 วิธีอัปเดตระบบในครั้งต่อๆ ไป (เมื่อคุณแก้โค้ดเสร็จ)
จากนี้ไป เมื่อคุณพิมพ์แก้โค้ดในเครื่องเสร็จ และอยากให้เว็บอัปเดต
คุณทำแค่ 3 คำสั่งสั้นๆ นี้ใน Terminal/Command Prompt:

   git add .
   git commit -m "พิมพ์อธิบายสั้นๆ ว่าแก้ไขอะไรไป"
   git push

เมื่อพิมพ์เสร็จ Netlify จะดึงโค้ดใหม่ไปอัปเดตบนหน้าเว็บให้คุณอัตโนมัติ!
